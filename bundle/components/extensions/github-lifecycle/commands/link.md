# GitHub Lifecycle Link

Use native GitHub relationships for parent/sub-issues and dependencies.

Default mode is PLAN. Apply only when `$ARGUMENTS` references an approved
plan.

Before applying:

- verify both issues and supported topology;
- detect cycles;
- verify relationship type;
- confirm target parent/dependency;
- avoid issue-level Tasks unless independent coordination warrants them.

Read the relationship back and record evidence.
