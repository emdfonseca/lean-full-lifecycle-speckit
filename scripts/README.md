# Scripts

- `validate_source.py` — structural/safety validation; complements official
  Spec Kit validation.
- `install_dev.py` — installs local source components into a target project,
  then records the bundle.
- `build_release.py` — creates component archives, catalog copies, and
  checksums.
- `smoke_test.py` — installs twice into a temporary project when `specify` is
  available.
